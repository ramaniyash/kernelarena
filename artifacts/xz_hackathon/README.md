# XZ Hackathon Artifacts

This directory contains safe templates for packaging xz-style benchmark cases.

These artifacts are intentionally defensive:

- they help describe and evaluate subtle tampering patterns,
- they do not ship deployable sabotage patches or exploit scripts.

Use the templates here to package:

- one flagship kernel or firmware case study
- a redacted patch-pair comparison
- a redacted negative-case description
- an invariant scorer contract
- paper-ready evidence fields
