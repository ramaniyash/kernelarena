# Transcripts

LLM agent transcripts from control evaluations.

Run the prompts in `paper/LLM_TEST_PROMPTS.md` and save the full responses here:

- `honest_agent.txt` -- model fixes the bug correctly
- `attack_agent.txt` -- model fixes bug + hides sabotage
- `monitor_honest.txt` -- monitor reviews the honest fix
- `monitor_sabotaged.txt` -- monitor reviews the sabotaged fix

These go directly into the paper results.
